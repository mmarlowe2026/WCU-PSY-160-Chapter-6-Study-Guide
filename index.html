Key question: “Is this example about getting information in, keeping it, using it, or getting it back?”

1. Encoding, storage, and retrieval

Memory is the set of processes through which we encode, store, and retrieve information.

Process Meaning Example
Encoding Transforming incoming information into a form that can be represented in memory. Paying attention to a new name and connecting it to a familiar person.
Storage Retaining information over time. Information remains available between learning and a later test.
Retrieval Accessing stored information. Bringing a previously learned name to mind.
Encode → store → retrieve.
Encoding = get it in. Storage = retain it. Retrieval = get it back.

Failure can happen at different points

If you never attended to the details of a coin or passing license plate, the best explanation may be encoding failure. Seeing something repeatedly does not guarantee that you encoded every detail.

If you know a name but cannot access it right now, the problem may be retrieval. A failed attempt to remember does not, by itself, prove the information is gone.

Check yourself: Reading a name, retaining it overnight, and producing it the next day involve which processes?

Encoding, storage, and retrieval, respectively.

2. The three-stage model

The bank uses the traditional sequence sensory memory → short-term memory → long-term memory. This is a useful model, not a claim that all memory operates as a single one-way conveyor belt.

Store Main features Recognition clue
Sensory memory Very brief retention of relatively detailed sensory information. Most unattended information disappears quickly. A fleeting visual or auditory trace.
Short-term memory Limited-capacity, brief retention of information currently available for use. Holding a new number long enough to dial it.
Long-term memory Large-capacity retention over extended periods; retrieval is not always easy. Facts, skills, and experiences retained beyond the immediate moment.

Iconic vs. echoic

Type Modality Memory cue
Iconic memory Visual sensory information. Icon = image.
Echoic memory Auditory sensory information. Echo = sound.

Sensory memory can briefly preserve considerable detail, but that does not mean the trace will become a lasting, meaningful memory. Attention helps selected information enter further processing.

Bank-specific numbers: The supplied questions use approximately seven items for a traditional immediate digit-span example and 15–25 seconds for unrehearsed short-term retention. Learn those as the chapter’s introductory estimates, not universal limits. Capacity and duration depend on the task, chunking, attention, and interference.

The bank describes short-term memory as the stage at which information first has meaning. Use that contrast with a fleeting sensory trace; contemporary accounts describe more interaction among attention, perception, and memory.

Check yourself: A brief trace of a sound is iconic or echoic?

Echoic. Iconic refers to visual sensory memory.

3. Chunking, rehearsal, and working memory

Concept Definition Example
Chunking Grouping separate items into meaningful units. Remembering 2, 0, 2, 6 as the familiar year 2026.
Maintenance rehearsal Repeating information to keep it active. Repeating a code until you enter it.
Elaborative rehearsal Organizing information and connecting it to meaning or prior knowledge. Explaining how a new term relates to a familiar experience.
Working memory Temporarily holding and actively manipulating information. Keeping intermediate totals in mind during mental arithmetic.
Short-term retention = hold it.
Working memory = hold it and work with it.
Chunking = group it.
Elaboration = connect it.

One task can use multiple systems

While multiplying mentally, your intermediate numbers are in working memory. Multiplication facts you already know are retrieved from long-term memory.

Repeating a number can maintain it briefly, but meaningful organization is usually more useful for durable learning than repeating words without understanding.

Attention and stress

Working memory uses limited cognitive resources. A demanding conversation can compete with attention needed for driving or another task. Stress can also reduce its effectiveness.

Chunking makes better use of limited capacity by changing the unit being remembered; it does not make capacity unlimited.

Check yourself: Repeating a definition vs. explaining it with an example—what is the difference?

Repetition illustrates maintenance rehearsal. Explaining meaning and linking an example illustrates elaborative rehearsal.

4. Primacy, recency, and serial position

In an immediate free-recall task, people often remember items at the beginning and end of a list better than items in the middle. This pattern is the serial-position effect.

Effect What is remembered better? Typical introductory explanation
Primacy Early items in a list. Early items often receive more rehearsal and support from longer-term retention.
Recency Late items in a list. Recent items can still be readily available at immediate recall.
Primacy = first.
Recency = recent / last.
The middle is often the weakest part in immediate list recall.

Example: A shopping list begins with bread and apples and ends with soap and rice. Remembering bread and apples especially well reflects primacy. Remembering soap and rice especially well reflects recency.

These are patterns, not guarantees. Delay, distraction, rehearsal, and task design can change them. An intervening distraction commonly reduces an immediate recency advantage.

Check yourself: Remembering the first lines of a poem better than the middle reflects what?

Primacy. Better memory for its last lines at immediate recall reflects recency.

5. Types of long-term memory

Long-term memory includes multiple distinguishable forms. They interact, but remembering a fact is not the same task as performing a practiced skill.

Type Main meaning Example
Explicit / declarative Conscious recollection of facts and events. Deliberately remembering a course concept.
Semantic General knowledge, concepts, facts, and word meanings. Knowing what “retrieval” means.
Episodic Memory for personally experienced events with a particular context. Remembering your first day of class.
Implicit / nondeclarative Past experience influences performance without requiring conscious recollection of that experience. A practiced skill or a priming effect.
Procedural Memory expressed through learned skills and procedures. Playing a familiar guitar passage.
Autobiographical Memory about one’s own life, including personal experiences and personal knowledge. Remembering a family holiday or facts about your childhood home.
Semantic = facts.
Episodic = episodes.
Procedural = practiced procedures.
Autobiographical = your life.

Hierarchy to remember

  • Declarative / explicit: includes semantic and episodic memory.
  • Nondeclarative / implicit: includes procedural skills, priming, and some conditioning effects.

In this chapter, explicit and declarative are paired terms, as are implicit and nondeclarative. Procedural memory is one form of nondeclarative memory, not the whole category.

A personal event can be both episodic and autobiographical. Identify the distinction the question is asking about rather than assuming the categories never overlap.

Check yourself: Knowing the rules of a game vs. executing a practiced serve?

Knowing the rules is semantic/declarative knowledge. Performing the practiced serve expresses procedural memory.

6. Retrieval, cues, and memory tasks

Concept Meaning Example
Retrieval cue A stimulus or context that helps access stored information. A song brings back an earlier trip.
Recall Producing information rather than selecting it from supplied alternatives. Writing an essay answer or filling a blank without options.
Recognition Identifying previously encountered information among presented material. Selecting a learned definition from four choices.
Tip-of-the-tongue phenomenon A temporary inability to retrieve information accompanied by a feeling of knowing it. Knowing a name starts with M but not accessing the full name.
Spreading activation Activation of one concept facilitates activation of related concepts in an associative network. Thinking of a beach brings sand, waves, and summer to mind.
Recall = produce.
Recognition = identify.
Tip of the tongue = access problem.

A typical multiple-choice question involves recognition and explicit memory: you intentionally identify the learned answer. An essay or a fill-in-the-blank item without options requires recall.

Recognition often supplies more cues than free recall, but it is not error-free. Familiar-looking distractors can still be wrong.

Semantic networks

Knowledge can be represented as interconnected concepts. In spreading activation, thinking about one concept activates related information. This helps explain why one memory can bring others to mind.

Check yourself: A familiar smell helps you remember a visit. What is the smell doing?

It is acting as a retrieval cue.

7. Depth of processing and priming

Levels of processing

The levels-of-processing approach emphasizes how information is mentally analyzed. Attending to meaning and connecting information with existing knowledge generally produces more durable retention than focusing only on surface features.

Processing emphasis Example Study implication
Shallow / surface Noticing the font, capitalization, or color of a word. Appearance alone is a weak basis for understanding.
Sound-based Considering how a word sounds or whether it rhymes. Sound can be useful, but it is different from explaining meaning.
Meaning-based / deeper Explaining a concept and relating it to a known situation. Generate examples, comparisons, and explanations.
Do more than highlight: explain why an answer is correct, connect it to prior knowledge, and create a new example.

Priming

Priming occurs when previous exposure influences later processing or performance. A related word may become easier to identify without conscious recollection of the earlier exposure.

Spreading activation describes activation moving through a network; priming describes an influence of previous exposure on later performance. The concepts are related, but the terms are not interchangeable in every question.

Implicit influences

Some conditioned responses and automatic associations can operate without deliberate recollection. The bank connects implicit associations to prejudice and discrimination. Do not assume that every implicit association determines someone’s conscious beliefs or behavior.

Check yourself: Which is deeper—counting letters in “consolidation” or explaining it using an example?

Explaining its meaning with an example is deeper, meaning-based processing.

8. The biology of memory

Term or structure What to remember Avoid this confusion
Hippocampus Important for forming and consolidating new declarative memories; also involved in spatial memory. It is not the permanent storage location of all memories.
Amygdala Contributes to emotional significance and emotional learning; can influence memory for emotional events. It is not a complete storage center for every emotional experience.
Consolidation Processes through which memories become more stable over time. Stability does not mean memories become permanently unchangeable.
Long-term potentiation: LTP A lasting increase in synaptic effectiveness following particular patterns of activity. It is not simply a synonym for storing a memory or growing new neurons.
Engram The physical representation or trace of a memory in neural systems. It is not the name of one anatomical organ.
Consolidation = stabilize.
LTP = strengthen synaptic effectiveness.
Engram = physical memory trace.

An emotionally significant event can involve both the hippocampus and amygdala. A later reminder may reactivate associated emotional and contextual information.

The bank’s London taxi-driver example connects spatial experience with hippocampal differences. It supports studying the relationship between experience and brain organization; it does not mean every association by itself proves a simple causal explanation.

Check yourself: A pathway responds more effectively after repeated activation. Which term fits?

Long-term potentiation. Consolidation refers more broadly to stabilization of memories.

9. Reconstructive and autobiographical memory

Remembering is a constructive process: stored information is combined with interpretation, current knowledge, and other available information. Memory is not a perfect recording.

Concept Meaning Example
Schema An organized framework of knowledge about a situation or category. Expecting a lecture to involve students, notes, and questions.
Constructive processing The meaning assigned to events influences how they are remembered. Remembering a routine detail that fits expectations even though it was absent.
Source amnesia Remembering information but forgetting where it came from. Knowing about an event but forgetting whether you heard it from a friend or a podcast.
Flashbulb memory A vivid memory of the circumstances in which one learned about a surprising or significant event. Remembering where you were when you heard major news.
Autobiographical memory Memory about your own life; it is selective and reconstructive. Recounting a childhood family celebration.
Vividness and confidence do not guarantee accuracy. Flashbulb memories can feel exceptionally clear while containing incorrect details.

Schemas help organize and interpret information, but they can also bias encoding and recall. They do not guarantee accurate detail.

Different periods of a person’s life are not equally accessible. Autobiographical memories can change with current interpretations and later information.

Check yourself: Remembering the news but not who told you illustrates what?

Source amnesia. The information is remembered, but its source is not.

10. Eyewitness memory, recovered memories, and culture

Leading questions and misinformation

In the Loftus and Palmer research described by the bank, changing the wording used to describe a vehicle collision influenced participants’ responses. The central lesson is that leading questions and post-event information can influence memory reports.

A memory report should not be treated as a literal recording simply because it is detailed or confidently expressed.

Repressed or recovered memories

The bank uses repression for the proposed process of pushing a distressing memory out of awareness. A later recollection alone does not establish that repression caused the earlier lack of recall or that every recalled detail is accurate.

Central challenge: distinguishing accurate recollection from error or suggestion. Do not assume that all recovered memories are true, or that all are false. Independent evidence matters.

Culture and remembering

Cultural practices can shape what people attend to, how they organize experience, and which learning or remembering strategies they use. Do not confuse different strategies or task experience with a simple ranking of cultures by memory ability.

The bank treats the relationship between written language and general recall ability as inconclusive rather than as proof that writing automatically increases or decreases memory.

Check yourself: Does the word “smashed” in a question leave a witness’s report completely unchanged?

No. The research example illustrates how wording can influence judgments and later reports.

11. Why we forget

Forgetting can reduce the influence of irrelevant information, but forgetting has multiple causes. Identify which mechanism the scenario actually supports.

Explanation Meaning Example
Encoding failure Information was never adequately encoded. You cannot describe an unattended license plate.
Decay Memory traces weaken over time in the theoretical account. A trace becomes less accessible with time; time alone does not rule out other causes.
Interference Other learned information disrupts learning or retrieval. Competing phone numbers come to mind.
Cue-dependent forgetting Stored information is difficult to access without useful cues. A name returns when someone gives its first syllable.

Ebbinghaus and the forgetting curve

Hermann Ebbinghaus conducted early systematic research on forgetting. The classic curve shows relatively rapid initial forgetting followed by a slower rate of loss, rather than an equal amount lost each hour.

The exact curve depends on material, learning conditions, and the test. His findings do not mean every reader forgets a fixed proportion of a meaningful text.

Proactive vs. retroactive interference

Type Direction Example
Proactive interference Old information interferes with new information. Your old password keeps coming to mind when you try to recall the new one.
Retroactive interference New information interferes with old information. After learning a new password, you struggle to recall the old one.
Proactive: old → new.
Retroactive: new → old.
Ask which information is doing the interfering—not just which information is forgotten.

Proactive and retroactive are interference terms. Anterograde and retrograde are amnesia terms. Keep these two pairs separate.

Check yourself: A new address makes an older address harder to remember. Which interference?

Retroactive: newer information disrupts retrieval of older information.

12. Amnesia and memory disorders

Term Main distinction Memory cue
Retrograde amnesia Loss of access to memories from before the onset of injury or illness. Retro = looking backward.
Anterograde amnesia Difficulty forming lasting new memories after onset. Antero = moving forward.
Alzheimer’s disease A progressive brain disease affecting memory and other cognitive abilities; not a normal consequence of aging. Progressive changes in memory and cognition.
Korsakoff’s syndrome A severe memory disorder associated with thiamine deficiency, often in the context of chronic alcohol misuse. Thiamine, alcohol history, and major memory impairment.
Retrograde = before onset.
Anterograde = new memory formation after onset.
These describe memory patterns; they do not identify a cause by themselves.

In some amnesic conditions, forming new declarative memories is impaired while certain practiced skills remain available. This helps show that memory includes distinguishable systems.

The bank emphasizes early forgetfulness in Alzheimer’s disease and asks about broader language and problem-solving changes. Occasional forgetting alone does not establish that diagnosis.

Korsakoff’s syndrome is not simply “forgetting because of age.” Thiamine deficiency is central; chronic alcohol misuse is a common context, but not the only one. Memory difficulties can coexist with other cognitive or behavioral changes.

These are educational distinctions, not instructions for diagnosing a real person from a short scenario.

Check yourself: Which term concerns difficulty forming lasting memories after an injury?

Anterograde amnesia. Loss of pre-injury memories is retrograde amnesia.
